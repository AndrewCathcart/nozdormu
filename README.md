# Nozdormu

A Discord bot for a World of Warcraft: Forever guild: game lookups (`/item`, `/recipe`, `/mats`, `/train`, `/dungeon`), and posts for the things a guild wants to know about.

## Game data

- Items, recipes and class spells come from the game client's own data tables, as exported by [wago.tools](https://wago.tools).
- Dungeons, their bosses and loot, and scanned item stats come from [Spyglass](https://github.com/Karl-HeinzSchneider/WoW-Spyglass), Copyright (c) 2026 Karl-HeinzSchneider, under the MIT licence.
- Item and spell links go to [Wowhead](https://www.wowhead.com/forever).
